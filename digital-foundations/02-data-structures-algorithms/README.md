# 02. Data Structures & Algorithms

Hands-on implementations, Big-O complexity analyses, and foundational data structures.

---

## 📁 Subdirectory Structure
* **[`code/`](./code/)** — Implementations of core data structures (Arrays, Linked Lists, Stacks, Queues, Trees).
* **[`labs/`](./labs/)** — Performance execution logs, time/space complexity analysis, and benchmark tests.

---

## 🛠️ Core Competencies Index
* **Big-O Notation:** Time ($O(1)$, $O(n)$, $O(n^2)$) and Space complexity trade-offs.
* **Linear Data Structures:** Array memory contiguous layouts, Singly/Doubly Linked Lists, Stacks (LIFO), Queues (FIFO).
* **Searching & Sorting:** Binary Search, Bubble Sort, Insertion Sort, Quick Sort operations.
