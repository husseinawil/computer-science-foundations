1. Search Algorithm Comparison
------------------------------
* Linear Search: O(n) Time | O(1) Space | Input Requirement: Unsorted or Sorted
* Binary Search: O(log n) Time | O(1) Space | Input Requirement: Strictly Sorted

2. Performance Analysis at Scale
--------------------------------
* Dataset Size (n = 1,000,000 items):
  - Linear Search Worst-Case:  1,000,000 comparisons
  - Binary Search Worst-Case:  ~20 comparisons (log2(1,000,000))

----------------
[x] Divide-and-conquer strategy eliminates half the search space with each comparison.
