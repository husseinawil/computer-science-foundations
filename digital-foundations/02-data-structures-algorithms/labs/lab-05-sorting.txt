1. Sorting Algorithm Comparison Matrix
--------------------------------------
* Bubble Sort: O(n^2) Avg/Worst Time    | O(1) Space     | In-Place / Stable
* Quick Sort:  O(n log n) Avg Time      | O(log n) Space | Divide & Conquer

2. Scale Execution Benchmark Estimates
---------------------------------------
* Dataset Size (n = 100,000 items):
  - Bubble Sort Operations (n^2):    ~10,000,000,000 operations
  - Quick Sort Operations (n log n): ~1,660,964 operations

4. Key Takeaways
----------------
[x] Quadratic sorting algorithms degrade significantly as data scale expands.
[x] Quick Sort recursive partitioning reduces sub-problem sizes logarithmically.
