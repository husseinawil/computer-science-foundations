1. Memory Alignment Principles
------------------------------
* Hardware word alignment requires types to be aligned at memory addresses matching their byte boundaries.
* Compiler inserts implicit padding bytes when fields are ordered sub-optimally.

2. Execution Verification
-------------------------

----------------
